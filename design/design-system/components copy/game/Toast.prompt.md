A one-line status message in the game flow — never a floating notification, always inline above the board.

```jsx
<Toast tone="peek">👀 Ghi nhớ vị trí các thẻ…</Toast>
<Toast>✖️ Cặp tiếp theo được nhân đôi điểm!</Toast>
```

Copy is a full sentence with a leading emoji that names the effect: 💥 bomb, ✖️ double, 👁️ peek, ❄️ freeze, 🔀 reshuffle, 📡 reconnecting.
